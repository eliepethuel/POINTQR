# ADR-0001 — Consigner les décisions d'architecture

- Statut : accepté
- Date : 2026-11-20

## Contexte
Le projet est mené par phases ; plusieurs choix s'écartent du cahier des charges. Il faut en garder la trace.

## Décision
Chaque décision structurante fait l'objet d'un ADR court dans `docs/adr/NNNN-titre.md`
(contexte, décision, conséquences). Un ADR n'est jamais réécrit : il est remplacé par un nouveau (« Remplacé par ADR-XXXX »).

## Conséquences
L'historique des choix reste lisible ; toute contribution qui change une décision ajoute un ADR.
